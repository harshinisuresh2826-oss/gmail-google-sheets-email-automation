# Gmail to Google Sheets Email Automation

An automated workflow that captures incoming Gmail emails and stores important email details in Google Sheets using n8n.

## Project Overview

This project automates email tracking by connecting Gmail with Google Sheets through n8n.

Whenever a new email arrives, the workflow automatically extracts the email details and adds them as a new row in Google Sheets.

## Technologies Used

- n8n
- Gmail
- Google Sheets

## Workflow

1. Gmail Trigger detects incoming emails.
2. Email details are extracted.
3. Google Sheets receives the details.
4. A new row is automatically added.

## Data Stored

- Mail ID
- Sender Name
- Subject

## Key Features

- Automatic email tracking
- Real-time workflow execution (based on trigger polling interval)
- Automatic Google Sheets updates
- No manual data entry required

## Learning Outcome

This project helped me understand workflow automation, trigger-based execution, and integrations between Gmail and Google Sheets.
